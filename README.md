# Automotive Lights E-commerce Website

## Project Description
This project is a front-end prototype for an e-commerce website specializing in automotive lights. It includes the basic HTML structure, CSS styling, and initial JavaScript for user interaction.

## Current Status
- Initial front-end structure and styling are complete.
- Basic page templates for home, product listing, product detail, cart, checkout, login, registration, and user account are in place.
- Placeholder content and images are used.
- Some interactive JavaScript elements (cart total calculation, checkout form helper) are implemented.
- The design is responsive for various screen sizes.

**Further development is required for:**
- Advanced JavaScript interactivity (e.g., image carousels, comprehensive form validation).
- Full backend integration for dynamic content, user authentication, order processing, and payment gateways.
- Replacement of placeholder content with actual product data and images.
- Thorough testing and bug fixing.

## How to View
To view the website locally:
1.  Download or clone this repository to your computer.
2.  Navigate to the project's root directory (the directory containing this `README.md` file).
3.  Open the `index.html` file in your preferred web browser (e.g., Google Chrome, Mozilla Firefox, Apple Safari, Microsoft Edge).

## Technologies Used
- HTML5
- CSS3
- JavaScript (Basic)

## Features Implemented (Front-End Skeleton)
- **Homepage (`index.html`)**: Basic landing page structure.
- **Product Listing Page (`products.html`)**: Layout for displaying multiple products with category navigation placeholders.
- **Product Detail Page (`product_detail.html`)**: Layout for detailed view of a single product.
- **Shopping Cart (`cart.html`)**: Table display for cart items with dynamic quantity and total updates.
- **Checkout Page (`checkout.html`)**: Forms for shipping/billing information with payment placeholders.
- **User Authentication Pages**:
    - `login.html`: Login form.
    - `register.html`: Registration form.
- **User Account Page (`account.html`)**: Placeholder for user dashboard, order history.
- **Responsive Design**: Adapts to different screen sizes.
- **Family-Friendly Content**: All placeholder text and images are neutral.
